# Как подключить адрес northwhale.studio

Инструкция для владельца домена. Займёт около 10 минут. Потом нужно подождать от получаса до суток, пока адрес заработает.

Сайт студии уже выложен на хостинге Netlify. Осталось сказать домену northwhale.studio, где сайт лежит. Для этого в Namecheap добавляются две записи.

Namecheap по-английски. Названия кнопок даны так, как они написаны на сайте.

## Шаг 1. Откройте настройки домена

1. Войдите на https://www.namecheap.com.
2. Откройте **Domain List**.
3. Рядом с northwhale.studio нажмите **Manage**.
4. Найдите строку **Nameservers**. Там должно быть **Namecheap BasicDNS**.
   - Если стоит другое, выберите **Namecheap BasicDNS** и нажмите зелёную галочку.

## Шаг 2. Уберите старые записи

1. Откройте вкладку **Advanced DNS**.
2. В разделе **Host Records** найдите записи, у которых в столбце Host стоит `@` или `www`.
3. Удалите каждую такую запись: значок корзины справа.
   - Обычно это записи Namecheap по умолчанию: **CNAME Record** на parkingpage.namecheap.com и **URL Redirect Record**.
   - Записи для почты (MX, TXT) не трогайте.

## Шаг 3. Добавьте две записи

Первая запись, для адреса northwhale.studio:

1. Нажмите **Add New Record**.
2. Type: **A Record**.
3. Host: `@`
4. Value: `75.2.60.5`
5. TTL: **Automatic**.
6. Нажмите зелёную галочку справа.

Вторая запись, для адреса www.northwhale.studio:

1. Нажмите **Add New Record**.
2. Type: **CNAME Record**.
3. Host: `www`
4. Value: `northwhale-studio.netlify.app`
5. TTL: **Automatic**.
6. Нажмите зелёную галочку справа.

Проверьте: с Host `@` и `www` теперь ровно по одной записи, те две, что вы добавили.

## Шаг 4. Подождите

Namecheap обычно применяет записи за полчаса. Иногда это занимает до суток. Потом Netlify сам включит HTTPS — замок в адресной строке. Это бесплатно, делать ничего не нужно.

## Шаг 5. Проверьте

Откройте в браузере по очереди:

1. https://northwhale.studio — открывается сайт студии, слева от адреса замок.
2. https://www.northwhale.studio — адрес сам меняется на https://northwhale.studio.
3. http://northwhale.studio, без буквы s — адрес сам меняется на https://northwhale.studio.
4. https://northwhale.studio с телефона через мобильный интернет, без Wi-Fi.

Всё открылось — напишите нам. Мы проверим сайт целиком: оба языка, кейсы с роликами, телефон, картинку ссылки.

Сайт не открывается или замка нет через сутки — пришлите нам снимок экрана вкладки **Advanced DNS**.

Пароли от Namecheap никому не пересылайте, даже нам. Для этой настройки они не нужны.
