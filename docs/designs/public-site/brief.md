# Бриф: сайт студии на northwhale.studio

Продолжение сайта студии. Стиль сайта не меняется. Документ описывает то, что сделано в рабочей версии и обсуждено в чате задачи.

Поддерживает истории из документа «Истории пользователей» проекта:

- S8: студия отправляет заказчикам ссылку на сайт. Основная история задачи: без публичного адреса ссылку не отправить.
- S1: заказчик видит кейсы в движении: круглые превью на стене играют.
- S6: сайт быстро открывается с телефона, в России и за рубежом.
- S9: студия меняет тексты без переделки дизайна: новая должность ШАНа.

## Задача

Сайт студии готов, но открывается только на тестовом сервере, во внутренней сети. Заказчики его не видят. Студия купила домен northwhale.studio. Нужно выложить сайт на бесплатный хостинг под этим адресом, с HTTPS, для русской и англоязычной аудитории. У заказчика нет программиста: его шаги должны быть простыми и короткими.

В ходе задачи вы попросили ещё две правки: должность ШАНа «Продукт-менеджер» и живые круглые превью кейсов там, где они стояли.

## Для кого

- Потенциальный заказчик. Открывает ссылку с компьютера или телефона, из России или из-за рубежа.
- Студия. Отправляет ссылку заказчикам.
- Вы. Подключаете хостинг и выпускаете новые версии.

## Что было до задачи

- Сайт собирается сервером при запуске. Работает только там, где запущен этот сервер.
- Публичного адреса нет.
- При уменьшении движения в системе круглые превью кейсов стояли. Кнопка паузы в этом режиме показывала «играть», но ничего не делала.
- Если телефон не давал роликам играть самим (iPhone в энергосбережении), превью стояли навсегда.
- У ШАНа была должность «Проджект-менеджер».

## Выбор хостинга

Сравнили четыре бесплатных хостинга по вашим условиям: бесплатно навсегда без карты, свой домен с HTTPS, ролики до 20 МБ, приватный репозиторий, ролики частями, доступ из России и из-за рубежа, выкладка из git.

- Cloudflare Pages. Лучшие лимиты: трафик без ограничений. Но с июня 2025 года российские провайдеры замедляют Cloudflare: из России грузятся только первые 16 КБ, сайт не открывается. Не подходит.
- Vercel. Бесплатный тариф только для некоммерческих сайтов. Сайт студии коммерческий. Не подходит.
- GitHub Pages. С приватным репозиторием только платно. С мая 2026 года GitHub хуже открывается из России. Не подходит.
- Netlify. Бесплатно, без карты, коммерческие сайты разрешены. Свой домен с HTTPS, выкладка из приватного репозитория. Массовых блокировок в России нет, есть единичные жалобы. Выбран.

Ограничение Netlify: 300 кредитов в месяц. Это около 15 ГБ трафика; каждая выкладка стоит 15 кредитов. Главная страница — около 1 МБ, полный ролик кейса — от 1 до 19 МБ. Хватит примерно на 10 000 посещений без роликов или на 1500–2000 с одним роликом. При превышении сайт выключается до следующего месяца. Платный тариф — от 9 $ в месяц.

## Что сделано

Сайт для хостинга:

- Одна команда собирает весь сайт готовыми файлами в папку: страница, код, стили, ролики, шрифты, картинки.
- Картинка ссылки в мессенджерах ведёт на northwhale.studio.
- Виджета багов доски на публичном сайте нет. На тестовом сайте и staging он остаётся.
- Своя страница 404 в стиле сайта, на двух языках.
- Адрес /health показывает, какая версия сайта выложена.
- Браузер хранит ролики и шрифты сутки, код сайта — пока он не поменяется. Страницу проверяет при каждом заходе: новая версия видна сразу.
- Все проверки сайта в браузере проходят и на этой сборке: оба языка, разделы, кейсы с роликами, музыка, игра с китом, телефон.

Выкладка:

- Netlify сам собирает сайт из ветки production в GitHub при каждом её изменении. Токены не нужны.
- Основной адрес — northwhale.studio. С www Netlify переводит на него.
- Инструкция для вас: регистрация в Netlify, подключение репозитория, домен, HTTPS, лимиты.
- Инструкция для заказчика: две записи DNS в Namecheap и проверка HTTPS.

Правки по вашим просьбам:

- ШАН — «Продукт-менеджер», по-английски Product Manager.
- Круглые превью кейсов играют и при уменьшении движения в системе. Кнопка паузы в этом режиме работает и останавливает их.
- Если браузер не даёт роликам играть самим, превью запускаются после первого касания страницы.
- Полный ролик кейса и ролик Марии на бейдже при уменьшении движения по-прежнему ждут нажатия.

## Подход

Сайт уже собирается в памяти при запуске сервера. Та же сборка теперь записывается в файлы, без сервера. Тестовый сайт и staging работают как раньше, на сервере. Все проверки в браузере прогоняются и на сервере, и на файлах.

Другие варианты:

- Выкладывать сам сервер на платный хостинг. Отклонено: вы просили бесплатный.
- Собирать сайт у себя и выкладывать в GitHub Actions с токеном Netlify. Отклонено: больше шагов и секрет в GitHub. Встроенная сборка Netlify проще.

## Порядок запуска

1. Выпуск в общую версию проекта.
2. Ветка production из общей версии. На это нужно ваше разрешение: спрошу перед тестом.
3. Вы подключаете Netlify по инструкции.
4. Заказчик добавляет записи в Namecheap.
5. Мы проверяем живой сайт: главная, оба языка, кейс с роликом, телефон, картинка ссылки, версия на /health, отсутствие виджета багов.

## Что не входит

- Оплата Netlify и рост трафика сверх бесплатного тарифа.
- Проверка доступа с российских провайдеров изнутри России: у нас нет точки проверки там. Проверите вы или заказчик, с телефона через мобильный интернет.
- Почта на домене northwhale.studio.
- Аналитика посещений.
