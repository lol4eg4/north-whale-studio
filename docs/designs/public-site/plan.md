# План: сайт студии на northwhale.studio

Основа: Бриф и истории. Прототип на ветке уже делает всё из брифа. План доводит его до выпуска и ничего не перестраивает.

## Что уже есть

- Статическая сборка: одна команда кладёт сайт в папку для хостинга. Тот же код страницы, что на сервере, тот же хеш в адресах кода и медиа, полный адрес картинки ссылки, страница 404, версия сайта на /health, без виджета багов.
- Настройки Netlify: команда сборки, папка, версия Bun, правила кеша, переадресация /health.
- Все проверки в браузере можно прогнать на сборке, отданной как на Netlify, со сжатием текста.
- Должность ШАНа.
- Круглые превью играют при уменьшении движения; кнопка паузы в этом режиме работает; отказ браузера в автозапуске ждёт касания.
- Две инструкции: для владельца репозитория (Netlify) и для заказчика (Namecheap).

## Задачи

1. Сборка для хостинга (S1, S2, S4, S6, S9). Готово. Проверка: тест сборки — всё из папки сайта на месте, каждый адрес со страницы и из кода есть в сборке, хеш совпадает с кодом, картинка ссылки с полным адресом, нет виджета и адреса внутренней сети, /health с коммитом, 404 с кодом 404, команда без адреса сайта останавливается.
2. Настройки Netlify (S1, S6). Готово. Проверка: тест сборки читает правила кеша и переадресацию /health.
3. Сайт из сборки работает как с сервера (S2). Готово. Проверка: все проверки в браузере на сборке.
4. Живые превью (S3). Готово. Проверки: при уменьшении движения превью играют, бегущая строка стоит, пауза их останавливает; при отказе в автозапуске кадр стоит, попыток не больше шести, после касания превью играют; ролик Марии при уменьшении движения не грузится.
5. Должность ШАНа (S5). Готово. Проверка: данные команды и бейдж на двух языках.
6. Инструкции (S7, S8). Готово. Проверка: ручная вычитка, точные записи DNS.
7. Проверка живого сайта (S1, S2, S4, S6). После шагов владельца и заказчика: главная, оба языка, кейс с роликом и перемоткой, телефон, картинка ссылки, /health с коммитом выпуска, нет виджета, www переводит на адрес без www, HTTPS.

## Что может сломаться и что на это есть

- Netlify не найдёт Bun или установит пакеты своим способом. Команда сборки ставит пакеты сама, версия Bun задана. Проверим на первой выкладке; лог виден в Netlify.
- Netlify отдаст ролик целиком, а не частями: Safari не перематывает. Проверим на живом сайте запросом с диапазоном (задача 7).
- В ветке production нет кода выпуска: Netlify соберёт старую версию без сборки и упадёт. Ветку создаём из общей версии после выпуска.
- Имя проекта northwhale-studio в Netlify занято: запись www у заказчика будет другой. Инструкции говорят сообщить имя; поправим инструкцию заказчику.
- Кредиты Netlify кончились: сайт выключится до следующего месяца. Лимиты и где их смотреть — в инструкции.
- У посетителя в России заблокирован конкретный адрес Netlify. Проверить изнутри России мы не можем; инструкция просит проверить с телефона через мобильный интернет.
- Сборка без адреса сайта дала бы картинку ссылки без домена. Команда останавливается с ошибкой, тест это проверяет.
- Шаблон страницы потеряет строку виджета: сборка остановится, а не выложит виджет. Тест проверяет, что виджета в сборке нет.

## Не входит

- Платный тариф, рост трафика, почта на домене, аналитика: как в брифе.
- Счётчик посещений: ему нужен сервер, на статическом хостинге его нет. Остаётся в отложенных.
- Своя картинка ссылки для каждого кейса: отложено раньше.

## Проверки перед тестом

- Тест сборки и все быстрые проверки.
- Проверка типов.
- Все проверки в браузере: на сервере и на сборке.
