# Справочник: команды, адреса, данные и файлы сайта

Сухие факты о сайте North Whale Studio. Как ими пользоваться — в [how-to-update-content.md](how-to-update-content.md), почему так — в [explanation-site-design.md](explanation-site-design.md).

## Команды

- `bun install` — ставит пакеты для разработки.
- `PORT=<порт> bun serve.ts` — запускает сайт. Код страницы сервер собирает в памяти при запуске.
- `bun run test` — быстрые проверки без браузера: `platform`, `plugins`, `tools` и файлы `tests/*.test.ts`.
- `bun run e2e` — проверки в браузере Chromium из `tests/e2e`. Одна проверка: `bun test tests/e2e/<имя>.test.ts --timeout 60000`.
- `bun run check` — проверка типов TypeScript.
- `bun tools/media.ts` (то же, что `bun run media`) — собирает ролики и фото в `site/media`.
  - `--src <папка>` — исходники кейсов, по умолчанию `tmp/cases-src`.
  - `--only <номер>` — только один кейс.
  - `--team` — только бейджи команды.
  - `--team-src <папка>` — исходники команды, по умолчанию `tmp/team-src`.

## Настройки сервера

- `PORT` — порт. Обязателен.
- `DEV=1` — пересобирать страницу после правок в `platform/`, `plugins/`, `site/media/` и файле приложения.
- `APP` — файл приложения со списком плагинов. По умолчанию `app.json`. `app.light.json` — лёгкая версия без игры.
- `PUBLIC_ORIGIN` — адрес сайта, например `https://northwhale.studio`. Нужен картинке ссылки `og:image`: она требует полного адреса.

## Адреса

- `/` — страница. Язык выбирается так: `?lang=ru` или `?lang=en` в адресе, затем выбор из памяти браузера, затем язык браузера. Русский браузер получает русский, остальные — английский.
- `/#cases`, `/#services`, `/#manifesto`, `/#contacts` — страница у раздела.
- `/#top` — начало страницы. `/#finale` — финал с китом после подвала.
- `/#case-1` … `/#case-8` — страница с открытым кейсом. Неизвестный номер ведёт к стене.
  - «Дальше: имя кейса» меняет адрес на следующий кейс, новой записи в истории нет. У последнего кейса кнопка «Назад к стене» закрывает кейс.
  - «Написать нам» закрывает кейс и ведёт к `#contacts`.
- `#team` — ссылка «Команда» в меню и подвале. Она запускает перекличку команды на стене.
- `/health` — `{ "ok": true, "commit": "<коммит>" }`: какой код отдаёт сервер. По нему выкладка проверяет, что новая версия на месте.
- `/app.js`, `/app.css` — собранный код и стили страницы.
- `/media/…`, `/fonts/…`, `/whale.svg`, `/og.jpg`, `/favicon.svg` — файлы из `site/`. Ролики отдаются частями по запросу браузера. Файлы из `/media/` и `/fonts/` браузер хранит сутки. Страница просит медиа с `?v=<хеш>`, поэтому заменённый файл приходит сразу.
- Любой другой адрес отвечает 404.

## Память браузера

Сайт хранит в `localStorage` четыре значения. Браузер запретил хранение — сайт работает без памяти.

- `nws.lang` — язык: `ru` или `en`.
- `nws.sound` — звук: `1` включён, `0` выключен. Сначала звук выключен.
- `nws.paused` — движение на паузе: `1` или `0`.
- `nws.best` — рекорд в игре с китом, число очков.

## Файлы данных

Всё содержимое сайта лежит в `plugins/content/data/`. Текст в данных — пара `{ "ru": "…", "en": "…" }`.

- `cases.json` — восемь кейсов в порядке студии.
  - `id` — номер кейса, он же номер в адресе `#case-N` и в именах файлов роликов.
  - `client`, `what`, `result` — подписи. `what` и `result` могут быть `null`.
  - `size` — размер плитки: `xl`, `l` или `t`.
  - `kind` — `video` или `still` (картинка).
  - `sound` — у полного ролика есть звук.
  - `vertical` — вертикальный ролик.
  - `color` — цвет окна кейса, имя цвета из `platform/ui/tokens.css`. У каждого кейса свой. На `ink`, `cobalt`, `signal` и `royal` текст белый и рамка выделения лимонная, на остальных — чернила. На `buoy` и `jellyfish` рамка выделения чернильная. На `lemon` плашка результата, маркер и карточка результатов белые.
  - `press` — издания, которые писали о клиенте: `name`, `logo` (файл в `site/media/`), `ratio` (ширина логотипа к высоте), `scale` (во сколько раз крупнее рисовать логотип с мелкими буквами, обычно 1), `title` (заголовок статьи как у издания), `url`. Логотипы стоят на плитке под «В прессе», карточки статей — в окне кейса. `[]` — ничего.
  - `logos` — строка логотипов внизу карточки «Результаты»: партнёры DeckForge, платформы Dear Passengers. Поля `name`, `logo`, `ratio`, `scale`, как у `press`. Подпись над строкой — `results.logos` в `pages.*.json`. `[]` — ничего.
- `pages.ru.json`, `pages.en.json` — страницы кейсов в окне кейса, по номеру кейса. Номера в двух файлах одинаковые. Кейс без страницы показывает заглушки истории.
  - `eyebrow` — надзаголовок. Заголовок окна — имя клиента с плитки, `client` из `cases.json`.
  - `client`, `category` — строка «Клиент · Категория».
  - `lead` — вводный абзац. `media` — подпись на ролике.
  - `sections` — «Как мы это сделали», одна или несколько частей: `title`, `kicker` (строка через «·» или `null`), абзацы `text`.
  - `card` — карточка вроде «One batch»: `label`, `headline`, `copy`, `hand` (строка от руки). `null` — карточки нет.
  - `role` — «Наша роль»: `items` (таблетки), `deliverables` (что сдали).
  - `results` — `items` (`value` крупно, `label` подпись; `value` «↑» рисуется стрелкой), `note` и `logos` — подпись над строкой логотипов из `cases.json`, `null` у кейса без них. `null` — блока нет.
  - `links` — ссылки наружу: `label`, `url`. Открываются в новой вкладке.
  - `==фраза==` в тексте подсвечивается маркером.
- `clients.json` — стикеры клиентов на стене: `caseId`, `name`, форма `shape`, цвета `bg` и `fg`, `phone` — виден ли на телефоне.
- `brands.json` — лист «Наши клиенты» на стене: `name`, `logo` (файл в `site/media/`), `ratio`, `scale`, как у `press`. Логотипы грузятся у экрана и не раньше 2 секунд после загрузки.
- `services.json` — услуги: `title`, `phrase`, список `includes`; `main` — главная услуга.
- `team.json` — команда: `name`, `role`, `color`, `photo`; `video` — ролик вместо фото.
- `contacts.json` — `email`, `messengers` и `socials`. У записи с `url` ссылка, без `url` — печать «заглушка».
- `texts.ru.json`, `texts.en.json` — все надписи сайта по ключам. Ключи в двух файлах одинаковые.

## Ролики и фото

Файлы лежат в `site/media/`. Их делает `tools/media.ts` по настройкам из `tools/media.json`. Килобайт здесь — 1000 байт, мегабайт — миллион байт.

Страница просит ролики и фото кейсов и команды и музыку с хешем содержимого: `/media/c1.webp?v=1a2b3c4d`. Заменённый файл получает новый адрес, и браузер не покажет старый из своей памяти. Хеши считаются при сборке. Сервер разработки (`DEV=1`) пересобирает страницу сам, когда меняется `site/media`; обычный сервер после замены файла нужно перезапустить.

Для кейса с номером N:

- `cN.webp` и `cN-phone.webp` — неподвижные обложки плитки, кадр `poster`. Предел 120 КБ каждая.
- `cN-ring.mp4` — ролик круглого стикера: квадрат 320 на 320, до 8 секунд, без звука. Предел 600 КБ.
- `cN-ring.webp` — кадр круглого стикера, пока ролик не играет. Предел 30 КБ.
- `cN-full.mp4` — полный ролик для окна кейса. Предел 20 МБ.
- `cN-full.webp` — вместо полного ролика у кейса-картинки. Предел 300 КБ.

Для человека в команде с номером N:

- `team-N.webp` — фото 320 на 320 точек. Предел 40 КБ.
- `team-N.mp4` — короткий ролик вместо фото. Предел 250 КБ.

Ещё:

- `music.m4a` — музыка, петля 30,7 секунды. Предел 3,5 МБ. Откуда трек и как он нарезан — в [credits.md](credits.md).
- Вся папка — не больше 80 МБ.

## Плагины

Каждый блок сайта — папка `plugins/<имя>/`: `plugin.json` (имя, слой, что даёт и чем пользуется), `index.ts`, пустая версия `off.ts`, стили и проверки. Какие плагины включены, решает `app.json`.

- Слой 0: `content` — тексты, кейсы, язык.
- Слой 1, витрина: `hero` — первый экран, `wall` — стена кейсов, команда и перекличка, `case` — окно кейса, `service` — карточка услуги, `manifesto` — манифест, `contacts` — контакты, `footer` — подвал.
- Слой 2, игра: `drag` — перетаскивание, `dive` — «Рандомный кейс» и «Прибраться», `sound` — звуки и музыка, `cursor` — свой курсор с подписями, `slingshot` — кит в рогатке.
- Слой 3: `visits` — счётчик посещений. Выключен: едет пустой версией.

## Платформа

Общий код для всех плагинов лежит в `platform/`.

- `main.ts` — запускает плагины по слоям.
- `host.ts`, `events.ts` — что плагин получает от страницы: места на странице, события, память.
- `memory.ts` — память браузера с приставкой `nws.`.
- `motion.ts`, `spring.ts` — подвижные детали, пружины, перестановка, пауза.
- `text-binder.ts` — подставляет тексты и меняет их при смене языка.
- `frame/` — верхняя панель, меню, разделы страницы.
- `ui/` — цвета и размеры (`tokens.css`) и общие детали: стикер, плитка, кнопка, бегущая строка, печать «заглушка».

## Проверки в браузере

Файлы в `tests/e2e/`: `case`, `contacts`, `cursor`, `finale`, `light`, `page`, `perf`, `phone`, `play`, `rollcall`, `rollcall.regression-1`, `sections`, `service`, `sound`, `wall`. Каждая проверка сама запускает сервер на свободном порту.
