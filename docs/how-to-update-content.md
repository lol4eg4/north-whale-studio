# Как поменять содержимое сайта

Рецепты для частых правок: тексты, кейсы, контакты, команда, музыка. Содержимое лежит в `plugins/content/data/`, ролики и фото — в `site/media/`. После каждой правки запустите проверки: `bun run test` и `bun run e2e`.

## Поменять текст на сайте

1. Найдите текст в `plugins/content/data/texts.ru.json`.
2. Поменяйте его там и тот же ключ в `texts.en.json`.
3. Обновите страницу.

Слово в фигурных скобках, например `{n}` или `{title}`, сайт заменяет числом или названием. Не меняйте его. В новом тексте такое слово само не заменится: его подставляет код.

## Поменять подпись кейса

Подписи кейсов лежат в `plugins/content/data/cases.json`, по записи на кейс.

- `client`: имя клиента на плитке и в окне кейса.
- `what`: серая строка над именем на плитке: кто клиент или что сделали. `null` — вместо неё «Смотреть кейс».
- `result`: лимонные плашки результата, список. Плашек может быть несколько, как у Dear Passengers. `[]` — плашки нет.

Каждое поле с текстом — пара `{ "ru": "…", "en": "…" }`.

## Наполнить страницу кейса

Страница кейса — текст в окне кейса: надзаголовок, «Клиент · Категория», вводный абзац, «Как мы это сделали», карточка, «Наша роль», «Результаты», ссылки. Заголовок окна — имя клиента с плитки. Тексты лежат в `plugins/content/data/pages.ru.json` и `pages.en.json`, по номеру кейса. Поля — в [reference-site.md](reference-site.md#файлы-данных).

1. Скопируйте запись готового кейса, например `"3"`, под новым номером в оба файла.
2. Впишите тексты. Фразу для маркера окружите `==`, как `==так==`.
3. Нет карточки или результатов — поставьте `null`. Нет ссылок — `[]`.
4. Запустите `bun run test`: он сверит, что у кейса в двух языках одинаковое число абзацев, таблеток, результатов и ссылок.

Кейс без записи в `pages.*.json` показывает заглушки истории: ключи `case.task`, `case.did` и `case.result` в `texts.*.json`.

## Заменить ролик кейса

1. Положите исходный файл студии в `tmp/cases-src/`. Папка `tmp/` не попадает в git.
2. В `tools/media.json` у кейса укажите имя файла в `src`.
3. Там же выберите кадры. `poster` — секунда кадра для обложки плитки или имя картинки-превью из той же папки. `ringStart` и `ringLength` — фрагмент для круглого стикера, до 8 секунд. `ring` — центр круглого стикера. `phoneFocus` — центр обложки на телефоне. `crop` — часть кадра, которую оставить, если в записи экрана есть лишнее: `[x, y, ширина, высота]` в точках исходника.
4. Соберите файлы одного кейса: `bun tools/media.ts --only 3`.
5. Те же `size`, `kind` и `sound` поставьте кейсу в `cases.json`. Сами файлы их не сверяют. Для вертикального ролика поставьте там же `"vertical": true`.

В конце инструмент печатает размер каждого файла. Файл больше предела или пропавший файл — команда завершается с ошибкой. Пределы — в [reference-site.md](reference-site.md#ролики-и-фото).

## Добавить кейс

Новый кейс берёт следующий свободный `id`, сейчас 12. Номер на плитке сайт ставит сам: место кейса в списке.

1. Добавьте запись с `"id": 12` в список `cases` в `tools/media.json`. Поля те же, что у других кейсов.
2. Положите исходник в `tmp/cases-src/` и соберите файлы: `bun tools/media.ts --only 12`.
3. Добавьте запись с `"id": 12` в `cases.json`. Поля те же, что у других кейсов, включая `vertical`. Цвет панели `color` у каждого кейса свой.
4. Поставьте плитку `{ k: "tile", id: 12 }` в список `W` в `plugins/wall/layout.ts`. Список собран полосами: одна-две крупные плитки, рядом столбец стикеров. Ставьте плитку в полосу до последних четырёх ячеек: блок «Привет!», лист клиентов и два стикера клиентов закрывают стену. `narrow: true` — плитка в три колонки на планшете, рядом с другой такой же.
5. Запустите `bun test tests/e2e/wall.test.ts --timeout 60000`. Стена должна остаться без пустых мест на компьютере, планшете и телефоне.

## Снять кейс

1. Уберите его из `cases.json`, `pages.ru.json`, `pages.en.json`, `tools/media.json` и списка `W` в `plugins/wall/layout.ts`.
2. Уберите его стикер клиента из `clients.json` и поправьте номера `i` стикеров в `W`.
3. Удалите его файлы `site/media/c<id>*`. Его `id` больше никому не отдавайте: старые ссылки на него ведут к стене.
4. Проверьте стену, как в шаге 5 выше.

## Поменять контакты

Контакты лежат в `plugins/content/data/contacts.json`.

- Мессенджер с полем `url` становится ссылкой. Без `url` рядом стоит печать «заглушка».
- Соцсетей сейчас нет: `socials` — пустой список, и строки «Соцсети» на сайте нет. Запись в `socials` без `url` появится с печатью «заглушка». Для ссылки добавьте `url` в тип `Contacts` в `plugins/content/api.ts`. Затем передайте его в `group` в `plugins/contacts/index.ts`, как у мессенджеров.
- Telegram и WhatsApp настоящие. Telegram берут ещё наклейка на стене и ссылка в подвале.
- Почта настоящая, без печати. Новый адрес впишите в `email` и в строку `<noscript>` в `site/index.html`.

## Добавить клиента в «Наши клиенты»

Лист логотипов на стене берёт клиентов из `plugins/content/data/brands.json`, по порядку.

1. Положите логотип в `site/media/client-<имя>.svg`. Рисуется одним цветом, по прозрачности файла: белые буквы на плашке нужно вырезать, иначе плашка станет сплошной.
2. Добавьте запись: `name`, `logo`, `ratio` (ширина к высоте), `scale` (обычно 1).
3. Запустите `bun run test` и посмотрите лист на компьютере и телефоне.

## Поменять человека в команде

1. Положите фото в `tmp/team-src/`. Вместо фото можно короткий ролик.
2. В `tools/media.json`, в списке `team`, укажите файл в `src`. Для ролика добавьте `"video": true`. Для широкого фото задайте квадрат: `"crop": [x, y, сторона]` в пикселях исходника.
3. Соберите бейджи: `bun tools/media.ts --team`.
4. В `plugins/content/data/team.json` поменяйте `name`, `role` и `color`. `color` — имя цвета из `platform/ui/tokens.css`.
5. Там же проверьте пути. `photo` — всегда `/media/team-N.webp`. У ролика добавьте `"video": "/media/team-N.mp4"`, у фото уберите `video`.

## Заменить музыку

1. Возьмите трек с лицензией, которая разрешает сайт.
2. Нарежьте петлю по рецепту из [credits.md](credits.md) и замените `site/media/music.m4a`.
3. Перепишите [credits.md](credits.md): название, автор, лицензия, дата.

`bun run test` проверит, что файл — только звук, длиной от 30 до 120 секунд и не больше 3,5 МБ.

## Показать лёгкую версию

```sh
PORT=3000 APP=app.light.json bun serve.ts
```

Лёгкая версия — сайт без игры: без перетаскивания, «Рандомного кейса», звука, своего курсора и кита.
