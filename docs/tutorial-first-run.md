# Первый запуск: сайт на своём компьютере

Этот урок ведёт от чистой копии репозитория до работающего сайта и пройденных проверок. Нужны git и Bun. Займёт около 15 минут.

## 1. Поставьте зависимости

```sh
bun install
```

Bun ставит три пакета для разработки: типы Bun, ffmpeg для подготовки роликов и Playwright для проверок в браузере. Самой странице пакеты не нужны. Её код собирает сервер при запуске.

## 2. Запустите сайт

```sh
PORT=3000 DEV=1 bun serve.ts
```

- `PORT` обязателен: на нём сервер слушает.
- `DEV=1` пересобирает страницу после каждой правки в `platform/`, `plugins/`, `site/media/` и `app.json`.

Откройте в браузере адрес `127.0.0.1:3000`. В задаче на доске сервер запускают командой `paneweb up`: она берёт команду из `.paneweb.json` и сама выбирает порт.

## 3. Посмотрите страницу

1. Сайт открылся на языке браузера. Добавьте к адресу `/?lang=en`, и страница станет английской.
2. Нажмите «Смотреть кейсы». На плитках неподвижные обложки, а в круглых стикерах справа сверху играют ролики.
3. Наведите мышь на плитку. Язычок в правом нижнем углу загибается, а у кейса с результатом из подписи вылетает лимонный результат.
4. Нажмите на первую плитку. Откроется кейс, ролик заиграет сразу, а адрес станет `/#case-1`. Пролистайте текст справа: история, роль студии, «В прессе». Нажмите «Дальше: AG1» — откроется следующий кейс. Закройте кейс крестиком.
5. Нажмите на бейдж человека из команды. Бейдж вылетит со своего места крупно на середину экрана. Нажмите на него ещё раз: он улетит обратно.
6. Нажмите круглую кнопку «Рандомный кейс» справа внизу. Подсветка пробежит по стене и откроет случайный кейс.
7. Пролистайте в самый конец. Оттяните кита в рогатке и отпустите.

## 4. Поменяйте текст

1. Откройте `plugins/content/data/texts.ru.json`.
2. Поменяйте значение ключа `hero.title`.
3. Обновите страницу: заголовок первого экрана изменился.
4. Верните текст обратно.

Все тексты сайта лежат в двух файлах: `texts.ru.json` и `texts.en.json`. Ключи в них одинаковые.

## 5. Запустите проверки

```sh
bun run test     # быстрые проверки без браузера
bun run check    # типы TypeScript
bun run e2e      # проверки в браузере Chromium, несколько минут
```

Проверки в браузере сами запускают сервер на свободном порту. Playwright пишет, что браузера нет? Поставьте его: `bunx playwright install chromium`.
