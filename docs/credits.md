# Credits

## Logos: site/media/{client,partner,platform,press}-*.svg

Each logo is the trademark of its owner. The site shows it only to name a client, a publication that wrote about a case or the platform its results come from. Every file is one colour: the site draws it through a CSS mask, so only its shape counts. A test (`plugins/content/tests/content.test.ts`) keeps scripts, event handlers, embedded pictures and outside addresses out of these files.
